# Fluer

A web-based system for ordering and tracking construction materials on residential building projects in Kenya. Site managers place material orders, suppliers confirm and update them, and builders can see when materials will reach the site.

DBT 1305, Web Application Development. Team Fluer: Johannes Vadera, 226806.
